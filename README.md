# 🎓 eLearning App Backend API

A robust, scalable backend built with **Node.js** and **Express.js**, following **Clean Architecture** principles to ensure maintainability and testability.

## 🛠️ Tech Stack
* [cite_start]**Runtime:** Node.js 
* [cite_start]**Framework:** Express.js 
* [cite_start]**Database:** MongoDB with Mongoose 
* **Security:** JWT (JSON Web Tokens) & Bcrypt
* [cite_start]**Architecture:** Clean Architecture (Entities, Use Cases, Controllers, Infrastructure) [cite: 11]

## 🚀 Key Features
* **Authentication:** Secure user signup and login with hashed passwords.
* **Course Management:** CRUD operations for courses, categories, and lessons.
* **Progress Tracking:** API endpoints to track student completion rates.
* **Scalable Routing:** Modular route structure for easy expansion.

## ⚙️ Installation & Setup
1. Clone the repository: `git clone https://github.com/Rynd2025/elearningapp-backend.git`
2. Install dependencies: `npm install`
3. Configure Environment: Create a `.env` file with your `MONGO_URI` and `JWT_SECRET`.
4. Run the server: `npm start`
